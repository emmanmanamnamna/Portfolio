MAMA’S RECIPE

A PERSONALIZED AND CUSTOMIZABLE MEAL PLANNER AND DIETITIAN ADVISORY APPLICATION. The system is developed using Flutter and the Dart programming language for building both the mobile application and the web-based admin platform. The backend is powered by Firebase, utilizing Firebase Authentication for secure login, Firestore Database for real-time data storage and synchronization, Firebase Storage for meal plan media, and Firebase Cloud Messaging for system notifications. This combination provides a scalable, cross-platform, and real-time architecture that enables seamless interaction between users, dietitians, and administrators.
